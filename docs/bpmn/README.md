# Diagramas BPMN

## `entrega/` — fuente de verdad

Los 10 diagramas de la **Primera Entrega** (5 procesos × AS-IS / TO-BE),
copiados sin modificación desde `ANEXOS/BPMN_s/`. Formato draw.io
(`app.diagrams.net`); los originales venían sin extensión.

Este es el material oficial frente al cual se evalúa el proyecto. Ante
cualquier discrepancia con los diagramas sueltos de este directorio,
prevalece `entrega/`.

## Archivos en la raíz — material previo

`PROCESO_AS_IS.drawio`, `PROCESO_TO_BE.drawio`, `PROCESO_TO_BE.puml` y los
PNG/SVG asociados son versiones anteriores del equipo, previas a la entrega.
Se conservan por historial; no usar como referencia.
